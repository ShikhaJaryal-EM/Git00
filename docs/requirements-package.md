## Project Summary

- Capture employee **First Name**, **Last Name**, **Email** (unique identifier), and **Active/Inactive** status
- **Create**, **edit** (names and email only), **deactivate**, and **reactivate** employees
- Runs **locally** in the browser; data **persists** between sessions
- **Single instance**; no roles, permissions, or security

**Requirements approved.** Solution design and implementation are out of scope for this package.
