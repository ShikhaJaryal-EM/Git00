# Non-Functional Requirements

**Version:** 1.0  
**Status:** Approved

## NFR-1.1 Local Execution

The application shall run locally on the user's machine. No cloud or other outside resources are required.

## NFR-1.2 Persistence

Employee data shall persist between sessions.

## NFR-1.3 Single Instance

The application shall run as a single instance at a time.

## NFR-1.4 User Interface

The application shall provide a functional UI in the browser. Visual polish is not a priority.
