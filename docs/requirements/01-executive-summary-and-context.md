# Executive Summary & Business Context

**Version:** 1.0  
**Status:** Approved

## Executive Summary

The Employee Directory is a **local web application** for capturing and managing employee records. Users interact with the application through a browser; all data and processing remain on the local machine.

The tool supports creating employee records, editing employee details, and changing status between Active and Inactive. There is no permanent delete — deactivation is the only way to remove an employee from active use.

## Business Context

A tool to capture the names of employees and manage their Active/Inactive status on a single machine, without cloud or other outside resources.
