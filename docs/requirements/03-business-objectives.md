# Business Objectives

**Version:** 1.0  
**Status:** Approved

## Objectives

| ID | Objective | Success Indicator |
|----|-----------|-------------------|
| **BO-1** | Maintain a complete roster of all employees | All employees (Active and Inactive) are visible in one list |
| **BO-2** | Keep employee information accurate | Users can edit names and email addresses |
| **BO-3** | Distinguish active from inactive employees | Active and Inactive status is clearly visible; deactivation preserves records |
| **BO-4** | Prevent duplicate employee records | Email uniqueness is enforced with clear feedback |
| **BO-5** | Operate locally | Application runs on the local machine with no cloud or outside resources |
| **BO-6** | Retain data across sessions | Employee list persists between sessions |
