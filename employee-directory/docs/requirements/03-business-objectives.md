# Business Objectives

**Version:** 1.0  
**Status:** Approved

## Objectives

| ID | Objective | Success Indicator |
|----|-----------|-------------------|
| **BO-1** | Maintain a complete roster of all employees | All employees (Active and Inactive) are visible in one list |
| **BO-2** | Keep employee information accurate | Users can edit names and email addresses at any time |
| **BO-3** | Distinguish current from former employees | Active and Inactive status is clearly visible; deactivation preserves records |
| **BO-4** | Prevent duplicate employee records | Email uniqueness is enforced with clear feedback |
| **BO-5** | Operate without external dependencies | Application runs entirely on the local machine |
| **BO-6** | Retain data across sessions | Employee list survives application restarts |

## Non-Objectives

These are explicitly **not** goals of this project:

- Replacing a full HR or payroll system
- Supporting multiple concurrent users
- Providing audit trails, reporting, or analytics
- Enforcing access control or data security
