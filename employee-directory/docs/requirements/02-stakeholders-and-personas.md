# Stakeholders & Personas

**Version:** 1.0  
**Status:** Approved

## Stakeholders

| Stakeholder | Interest |
|-------------|----------|
| **Office / HR Administrator** | Maintain an accurate, up-to-date employee list |
| **Project Sponsor** | Simple local tool with no external dependencies or security overhead |
| **Developer / Implementer** | Clear, unambiguous requirements for a focused build |

## Persona: Office Administrator

**Name:** Alex  
**Role:** Office or HR administrator  
**Technical comfort:** Comfortable using web applications in a browser; no technical setup expected beyond starting the app

### Goals

- Quickly add new employees when they join
- Update employee names or email addresses when they change
- Deactivate employees who leave the organization
- Reactivate employees who return
- See the full employee roster at a glance, including inactive employees

### Frustrations

- Losing data when the application is closed
- Unclear error messages when entering invalid or duplicate information
- Unnecessary complexity (login screens, permissions, cloud setup)

### Usage Context

- Uses the application on a single workstation
- Runs one instance at a time
- Does not share access with other users concurrently
